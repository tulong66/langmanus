# システムアーキテクチャ概要

## 全体構成

Qwen2.5-Omniモデルとブラウザエージェントの統合システムは、以下の主要コンポーネントで構成されています：

```
┌─────────────────┐      ┌───────────────────┐      ┌─────────────────┐
│                 │      │                   │      │                 │
│  ユーザーインターフェース │ ──→ │  LangManus エージェント │ ──→ │  ブラウザ (Chrome) │
│                 │      │                   │      │                 │
└─────────────────┘      └───────────────────┘      └─────────────────┘
                                   │
                                   ↓
                         ┌───────────────────┐
                         │                   │
                         │  QwenOmniWrapper  │
                         │                   │
                         └───────────────────┘
                                   │
                                   ↓
                         ┌───────────────────┐
                         │                   │
                         │  Replicate API    │
                         │  (Qwen2.5-Omni)   │
                         │                   │
                         └───────────────────┘
```

## コンポーネント詳細

### 1. QwenOmniWrapper

- **役割**: Qwen2.5-OmniモデルをLangChainフレームワークと互換性を持たせるためのカスタムラッパー
- **主要機能**:
  - LangChainの`BaseChatModel`を継承
  - `bind_tools`メソッドの実装
  - メッセージフォーマットの変換
  - ツール使用のサポート

### 2. LangManus エージェント

- **役割**: ユーザーの指示を解釈し、適切なブラウザ操作を計画・実行
- **主要コンポーネント**:
  - ブラウザツール
  - プロンプトテンプレート
  - エージェントフレームワーク

### 3. ブラウザインターフェース

- **役割**: 実際のブラウザ操作を実行
- **技術**: Playwright/Selenium
- **機能**: ナビゲーション、クリック、入力、スクリーンショット取得など

### 4. Replicate API連携

- **役割**: Qwen2.5-Omniモデルへのアクセス
- **機能**: 
  - APIキー管理
  - リクエスト/レスポンス処理
  - エラーハンドリング

## データフロー

1. ユーザーがタスクを入力
2. LangManusエージェントがタスクを解釈
3. QwenOmniWrapperを通じてQwen2.5-Omniモデルに指示を送信
4. モデルからの応答に基づいてブラウザ操作を実行
5. 操作結果（スクリーンショットなど）を再度モデルに送信して次のアクションを決定
6. 最終結果をユーザーに返す

## 技術スタック

- **言語**: Python
- **フレームワーク**: LangChain
- **モデル**: Qwen2.5-Omni (via Replicate)
- **ブラウザ自動化**: Playwright/Selenium
- **その他**: dotenv（環境変数管理）
