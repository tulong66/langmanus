# Qwen2.5-Omni ブラウザエージェント統合プロジェクト

このプロジェクトは、Qwen2.5-Omniモデルをブラウザエージェントと統合し、高度な視覚理解能力を持つブラウザ自動化システムを実現することを目的としています。

## ドキュメント構造

- **specs/** - 外部仕様書、機能要件、APIインターフェース定義
- **architecture/** - 内部アーキテクチャ、設計図、コンポーネント関係図
- **progress/** - 進捗状況、課題一覧、TODOリスト

## 主要コンポーネント

- Qwen2.5-Omniモデル（マルチモーダルLLM）
- LangManusブラウザエージェント
- カスタムLLMラッパー（QwenOmniWrapper）

## 開発ブランチ

- `feature/Qwen2.5-Omni` - 開発用ブランチ
